# FATYAK — المرصد الفلكي

موقع عربي مجاني لرادار الكواكب والمذنبات، ومواعيد الكسوف والخسوف القادمة. **المطوّر: FATYAK**.

واجهة متجاوبة، شعار SVG أصلي، وضع داكن/فاتح، بحث، محفوظات محلية، رادار مدارات/أفق، محاكاة زمنية، اختيار موقع الرصد، وتذكيرات تقويم ICS.

## ما الذي يعنيه «بدون API» هنا؟

- لا اتصال بخدمات NASA/JPL Horizons/SBDB API، ولا مفاتيح API، ولا اشتراكات بيانات.
- حساب مواقع الكواكب والظروف المحلية يتم في المتصفح بواسطة **Astronomy Engine 2.1.19** المدمج.
- أداة التحديث تنزّل **صفحات HTML وملف TXT وخلاصات RSS عامة** من المصادر الرسمية. ليست بيانات مختلقة أو إحصاءات «حية» وهمية.
- متصفح الزائر يقرأ ملفات JSON **ساكنة من الموقع نفسه**. هذه نُسخ منشورة محليًا، وليست طلبات إلى API فضائية.
- لا خرائط أو خطوط أو صور أو مكتبات من CDN في وقت التشغيل. الخطوط والصورة والمحرك مضمّنة محليًا.

## التشغيل المحلي

يتطلب Node.js 20.19 أو أحدث.

```bash
npm ci
npm run dev
```

يفتح الموقع على `http://localhost:5173`. هذا عنوان التشغيل على جهازك فقط؛ الكود في المتصفح لا يتصل بخادم بيانات على localhost.

الخادم يرتبط بـ `0.0.0.0` ويعمل مع معاينات البروكسي، ويقوم بتنزيل المصادر عند التشغيل ثم كل **6 ساعات**. يستعمل نُسخة البيانات المحفوظة عند تعذّر الاتصال؛ صفحة المصادر توضّح آخر تنزيل ناجح والخطأ بدل الادعاء بوجود تحديث جديد.

للتنزيل اليدوي من المصادر الرسمية:

```bash
npm run update-data
```

**زر «تحديث العرض» داخل الموقع** يعيد قراءة آخر نسخة منشورة على هذا الخادم. لا يُجبر مواقع الوكالات على تنزيل جديد في كل ضغطة؛ هذا مقصود لتجنّب الضغط على المصادر.

## النشر الدائم مجانًا — GitHub Pages

المشروع جاهز للنشر الساكن. لم يُسجّل نطاق باسم FATYAK، ولم يُنشر على حسابك بالنيابة عنك. المعاينة داخل المحادثة ليست استضافة دائمة.

1. أنشئ حسابًا ومستودعًا **عامًا** على GitHub باسم تختاره.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بما فيها `package.json` و`package-lock.json` والمجلد المخفي `.github`.
3. استخدم الفرع `main` (أو عدّل الفرع في الملف `.github/workflows/publish.yml`).
4. افتح **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. افتح **Actions → Update astronomy data and publish → Run workflow** إذا لم يعمل تلقائيًا.
6. يظهر رابطك في **Settings → Pages** بعد نجاح البناء. رابط GitHub الفرعي لا يحتاج شراء نطاق.

التحديث المجدول المرفق يقوم بتنزيل ملفات NASA/MPC/ESA وإعادة البناء والنشر كل 6 ساعات، بدون أسرار أو مفاتيح لخدمات فضائية. صلاحيات Pages التلقائية خاصة بمنصة النشر، وليست مفاتيح بيانات فضائية.

**حدود مهمة:** الجدولة قد تتأخر أو تُعطّلها GitHub في المستودعات العامة بعد فترة خمول. راجع تبويب Actions دوريًا، وأعد تفعيلها عند الحاجة. إذا تعطّلت الجدولة، يستمر الموقع بآخر نسخة موثقة ولن يدّعي أنها جديدة. خطط الاستضافة المجانية تخضع لحدود وسياسات مزوّدها؛ لا نعد باستضافة غير محدودة.

## بدائل النشر

```bash
npm run update-data
npm run build
```

مجلد `dist` هو الموقع الساكن الجاهز لرفعه على استضافة مثل Cloudflare Pages أو Netlify. يمكن استخدام خطة مجانية بحسب شروطها. **رفع الملفات مرة واحدة لا يصنع تحديثًا تلقائيًا**: فعّل عملية بناء مجدولة، أو أعد تشغيل التحديث والبناء والنشر بنفسك.

للإنتاج على خادم Node مستمر:

```bash
npm run build
npm start
```

`PORT=5173` افتراضي ويمكن تغييره بمتغير البيئة. كل البيانات تبقى ملفات ساكنة تحت `/data`؛ لا خدمة API خارجية.

## النسخة المستقلة HTML

ملف `FATYAK-Observatory.html` المرفق نسخة مستقلة: CSS وJavaScript والخطوط والصورة ومحرك الفلك والبيانات مضمّنة. يعمل دون إنترنت، بما في ذلك الحسابات الزمنية للكواكب. **لا يستطيع ملف HTML مستقل إعادة تنزيل جداول الوكالات تلقائيًا**؛ يعرض بياناته المحفوظة وتاريخها بوضوح. للتحديث الكامل استخدم الخادم أو النشر المجدول.

لإنشاء نسخة مستقلة جديدة بعد البناء:

```bash
npm run build
node scripts/make-standalone.mjs
```

## حدود الدقة العلمية

- **الرادار** تصور لمدارات أو أفق الموقع، وليس جهاز رادار فعليًا أو بثًا تصويريًا من السماء.
- مواقع الكواكب من Astronomy Engine؛ الأحجام والمسافات مضغوطة بصريًا وليست رسمًا بمقياس حقيقي.
- مواقع المذنبات تستعمل انتشارًا ثنائي الجسم لعناصر MPC، يدعم المدارات الإهليلجية والمكافئة والزائدية. لا ندمج اضطرابات الكواكب أو التسارع غير الجاذبي. ليس هذا مرجعًا لإحداثيات توجيه تلسكوب دقيقة.
- سطوع المذنبات: `H + 5 log10(Δ) + 2.5 k log10(r)` حسب معاملات الملف. **قيمة نموذجية، وليست قياسًا رصديًا**. نشاط المذنب قد يجعل السطوع الفعلي مختلفًا كثيرًا.
- يتراجع تقريب المذنبات بعيدًا عن تاريخ عناصرها. المحاكاة البعيدة تعليمية.
- **TD / TT** في جداول NASA وعناصر الحضيض هو التوقيت الأرضي الديناميكي، وليس UTC. يُحفظ الأصل كما نشرته الوكالة. العد التنازلي وتذكير ICS يستخدمان تحويل UTC تقريبيًا من Astronomy Engine، وليس ضمانًا لثوانٍ رصدية دقيقة.
- ظروف الكسوف الشمسي المحلية محسوبة للموقع. أوقات العرض تتبع المنطقة الزمنية **لجهاز المستخدم**؛ الموقع المختار لا يغيّر منطقة جهازه.
- فحص الخسوف المحلي يعرض ارتفاع القمر عند الذروة العالمية فقط، ولا يزعم رؤية كل المراحل.
- «فوق الأفق» ليس وعدًا بالرؤية؛ السطوع والنهار والطقس والتلوث الضوئي تؤثر أيضًا. الموقع لا يجلب بيانات طقس.
- تذكير التقويم يذكّر بالذروة العالمية التقريبية، وليس وقت بداية الحدث في مدينتك.

## الملفات والترخيص

- `src/`: الواجهة والحسابات والرسوم الأصلية.
- `scripts/update-data.mjs`: التنزيل والتحقق والنشر المحلي، بدون API.
- `public/data/`: آخر نُسخة مصدرية محفوظة، مع سجل تنزيل لكل مصدر.
- `public/logo-mark.svg` و`public/FATYAK-logo.svg`: الشعار المتجهي.
- `.github/workflows/publish.yml`: البناء والنشر المجدول.
- `tests/fixtures/`: لقطات المصدر المستخدمة في الاختبارات، وليست بيانات وهمية للتطبيق.
- `licenses/`: تراخيص المحرك والخطوط.

كود FATYAK والرسوم الأصلية تحت ترخيص MIT (ملف `LICENSE`). Astronomy Engine تحت MIT. خطا IBM Plex Sans Arabic وSpace Grotesk تحت OFL. بيانات NASA/MPC/ESA تعود لمصادرها وشروطها، ولا يغطي ترخيص الكود محتواها أو علامات الوكالات التجارية.
